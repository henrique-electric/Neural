# Trying to create a neural network using just calculus and linear algebra and C++

    This project Aims to create a basic functional neural network from scratch using only Eigen library for essential linear algebra operations.

    The main objective for now is to create a functional forward/backpropagation system


### Project structure:
    - `src/` : Contains the source code for the neural network implementation.
    - `include/` : Contains header files for the neural network classes and functions.
    - `tests/` : Contains test cases to validate the functionality of the neural network.
    - `CMakeLists.txt` : CMake configuration file for building the project.
